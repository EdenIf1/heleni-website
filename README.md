# HELENI · נגריית הלני

האתר של נגריית הלני, מושב אליפלט.
האתר החי: https://heleni.netlify.app

## מבנה הפרויקט

| קובץ / תיקייה | מה זה |
|---|---|
| `nagariyat-haleni-demo.html` | **קובץ המקור.** כל השינויים באתר נעשים כאן. |
| `images/` | התמונות של העבודות (p1–p8) והאייקונים. כל קובץ שמוסיפים כאן עולה לאתר. |
| `og-image.jpg` | התמונה שמופיעה כששולחים את הקישור בוואטסאפ. |
| `build.mjs` | בונה את האתר מקובץ המקור. Netlify מריץ אותו לבד בכל שינוי. |
| `build.ps1` | מריץ את `build.mjs` במחשב (לבדיקה לפני העלאה). |
| `netlify.toml` | אומר ל־Netlify להריץ את `build.mjs` ולפרסם את `site/`. |
| `site/` | האתר שמתפרסם (נוצר על ידי `build.mjs`, לא עורכים בו ידנית). |
| `site/_headers` | הגדרות האבטחה של השרת (נוצר על ידי `build.mjs`). |
| `tools/serve_with_headers.py` | שרת בדיקה מקומי עם הגדרות האבטחה. |

## עדכון האתר

עורכים רק את `nagariyat-haleni-demo.html`. אחרי שהשינוי נשמר ב־GitHub, Netlify בונה ומפרסם את האתר לבד תוך כדקה.

**מהטלפון:** נכנסים ל־https://github.com/EdenIf1/heleni-website, פותחים את `nagariyat-haleni-demo.html`, לוחצים על העיפרון ✏️, עורכים ולוחצים **Commit changes**.

**מהמחשב:** עורכים, מריצים `build.ps1` כדי לבדוק, ואז `git commit` ו־`git push`.

אם משהו נשבר, רואים את השגיאה ב־Netlify תחת Deploys, והאתר הקודם נשאר באוויר.

הערה: הפרסום האוטומטי עובד כי ה־repo ציבורי. בתוכנית החינמית של Netlify, ב־repo פרטי הפריסות נחסמות.

העלאה ידנית (רק אם צריך):

```powershell
npx -y netlify-cli@17.38.1 deploy --prod --dir site --site dfd0d907-8899-47e6-a51a-117bdeb052b5
```

## מה עוד פתוח

- אישור מדניאל לשימוש בתמונות מהאינסטגרם, ואישור אילו מהן הדמיות.
- אישור רשימת היישובים באזורי השירות.
- האם יש הסדרי נגישות בנגרייה עצמה (להוסיף להצהרת הנגישות).
- תמונות ברזולוציה גבוהה במקום התמונות מאינסטגרם (640 פיקסלים).
